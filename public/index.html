NAME #

tom — Tom Hesse

SYNOPSIS #

tom [OPTION] [FILE ...]

DESCRIPTION #

tom is a wetware for Linux platforms, preferably NixOS, but also works on Arch Linux, Ubuntu, Debian and Gentoo. tom works best with Neovim and VS Code.

OPTIONS #

-a, --ansible
read and write ansible playbooks and roles
-b, --bash
read and write bash scripts
-C
read and write C code (not fully implemented)
-html/-css
read and write HTML/CSS with limited proficiency
-mk
build and configure mechanical keyboards
-n, --nixos
configure and maintain NixOS systems and servers
-p, --python
read and write Python code
